# สร้าง Boilerplate ให้โปรเจกต์ของคุณใน 1 คำสั่ง ด้วย create-custom-stack\n\nเบื่อไหมที่ต้องมานั่งลง Next.js, Tailwind, Prisma, Zod ใหม่ทุกครั้งที่เริ่มโปรเจกต์? แล้วยังต้องมานั่ง Config ให้มันคุยกันรู้เรื่องอีก

ทำไมไม่สร้าง CLI ของตัวเองล่ะ? วันนี้ผมทำ `@chinawatdc/create-custom-stack` ออกมาเป็นต้นแบบให้ทุกคนลองเอาไปใช้ครับ

**วิธีใช้:**
```bash
npx @chinawatdc/create-custom-stack my-new-app
```
คำสั่งเดียวจบ รอระบบติดตั้ง เสร็จปุ๊บเริ่มเขียนโค้ดธุรกิจของคุณได้เลย ไม่ต้องเสียเวลาเซ็ตอัปโครงสร้างอีกต่อไป!

ถ้าอยากดูว่า CLI ทำงานยังไง ลองไปโหลดโค้ดมารื้อดูได้บน GitHub เลยครับ
